## Общая структура

- Список моделей (карточки) — выбор модели
- Под моделями: **dropdown** выбора режима (зависит от модели)
- Ниже: UI под выбранный режим

---

## Kling 3.0 Turbo

**Режимы (dropdown):**
- Image / Prompt
- Multishot

### Режим: Image / Prompt
- Промпт (текстбокс)
- Референс-изображение (опционально, из галереи — как уже есть)
- Resolution: 720p / 1080p
- Duration: 3–15 сек

### Режим: Multishot
- Общий промпт отсутствует — вместо него конструктор сцен
- Каждый шот:
  - Текстбокс с промптом
  - Слайдер длительности: 3–15 сек, дефолт 3 сек (макс = остаток от 15)
- Кнопка "+ Добавить шот":
  - Блокируется если сумма секунд = 15 или уже 6 шотов
- Счётчик: `"использовано X / 15 сек"`
- Изображения на шот — **не поддерживается** (API ограничение Turbo)
- Один глобальный первый кадр (опционально, сверху)

**Технические заметки:**
- Другой endpoint: `POST /image-to-video/kling-3.0-turbo`
- Другой формат body: `contents` array
- Другой формат ответа: `id` вместо `task_id`, `succeeded` вместо `succeed`
- Нужен отдельный API клиент
- Мультишот формируется в строку: `"shot 1, 5, desc; shot 2, 5, desc;"`

## Kling 3.0 & 3.0 Omni

**Режимы (dropdown):**
- Image / Prompt
- Multishot
- Motion Control
- ~~Element Management~~ — пропускаем пока
- ~~Voice Management~~ — не нужен, есть ElevenLabs

### Режим: Image / Prompt
- Промпт (текстбокс)
- Референс-изображение (опционально, из галереи)
- Resolution: 720p / 1080p / 4K
- Duration: 3–15 сек
- Первый кадр + Последний кадр (оба опциональны)

### Режим: Multishot (Omni)
- Конструктор сцен (аналогично Turbo)
- Каждый шот: текстбокс + слайдер длительности
- Счётчик `"X / 15 сек"`, блокировка при 15 сек или 6 шотах
- Дополнительно: `image_list` — несколько референс-изображений (до 7)
  - Персонаж, стиль, сцена — всё через `<<<image_1>>>` в промпте
- Режим генерации: `intelligence` (авто) / `customize` (ручной)

### Режим: Motion Control
> Перенос движения с видео на персонажа

- Фото персонажа (обязательно)
- Видео с движением (обязательно)
- Промпт (опционально — одежда, сцена и т.д.)
- Ориентация персонажа: **[По фото]** / **[По видео]** + tooltip с объяснением
- Звук из видео: вкл / выкл
- Режим: std / pro
- Лимиты (показывать при загрузке видео):
  - По фото: макс 10 сек
  - По видео: макс 30 сек
  - Мин 3 сек, форматы .mp4 / .mov, до 100MB

**Технические заметки:**
- Omni endpoint: `POST /v1/videos/omni-video`, модели: `kling-v3-omni`, `kling-video-o1`
- Motion Control endpoint: `POST /v1/videos/motion-control`, модели: `kling-v2-6`, `kling-v3`
- image_list: Base64 или URL, до 10MB, мин 300px, соотношение 1:2.5–2.5:1

## Avatar

**Без dropdown** — один режим:
- Фото аватара (обязательно)
- Аудио файл (обязательно) — .mp3/.wav/.m4a/.aac, макс 5MB, 2–300 сек
- Промпт (опционально — жесты, эмоции, движения камеры)
- Режим: std / pro

> TTS вкладка в Kling — не используем, есть ElevenLabs

**Технические заметки:**
- Endpoint: `POST /v1/videos/avatar/image2video`
- `sound_file`: Base64 или URL аудио

## Промпт-хелпер (GPT-4o)

Кнопка "✨ Улучшить промпт" рядом с текстбоксом.

**Что передаём GPT:**
- Выбранная модель и режим
- Короткое описание от юзера (или уже написанный промпт)
- Загруженные изображения (base64) — GPT видит картинки и пишет под них

**Обычный режим:**
- GPT возвращает один улучшенный промпт → вставляется в текстбокс

**Multishot режим:**
- GPT получает: общую идею + количество сцен + длительность каждой
- GPT расписывает нарратив пропорционально (3 сек = краткое действие, 7 сек = развёрнутая сцена)
- Возвращает массив промптов → каждый вставляется в свой текстбокс

## Настройки (model-dependent)

- **Quality** (720p Std / 1080p Pro / 4K): скрывать варианты которых нет у модели
- **Duration**: слайдер 3–15 сек (не кнопки)
- **Aspect Ratio**: только поддерживаемые соотношения модели
- **Sound**: показывать только если модель поддерживает (`supportsSound: true`)
